до summary; оригиналы остаются доступными. Семантическая оценка summary ещё не проведена.

это не полный сетевой TTFT и не стоимость запуска CLI. См. router-evaluation.json.

Gold присутствует для арифметики и отдельных общеизвестных фактов. Ответы моделей
на датасете не генерировались. Correctness/hallucination rate моделей, сравнительное
качество Flash/Argon/Codex и стоимость реальных ответов на этом наборе **не измерены**.
Нет категорий, доверенных Lite. Модельный расход eval/summary/classification — 0.

Контролируются идемпотентность, одинаковые намеренные вопросы, mock-изоляция,
возврат темы, таймер, scope, restart, online backup с WAL, коррекция/удаление фактов,
удаление queued-derived данных, cap фактического GoBot prompt, fresh CLI policy,
проверка перед speech, отсутствие повторного TTS при replay и cleanup дочерних процессов.

Новые ContextPacket/provider usage поля проверены фикстурами, но после этого изменения
новый платный CLI E2E не запускался. Ранее реальный Codex E2E успешен; Antigravity
успешно проверен владельцем из интерфейса. Это не заменяет нового сравнительного eval.

При добавлении визуального слоя runtime-инструкция сообщает о поддерживаемых
карточках, чтобы CLI не заявлял «только текстовый режим». Это увеличило начальный
ContextPacket на ~70 оценочных токенов. Hard cap прежний; весь визуальный JSON и
бинарные изображения в CLI context не добавляются. Четыре weather eval случая
теперь идут в visual TOOL с явным unavailable, не в внешнюю verification. Это
проверка политики доступности, а не проверенная погодная интеграция.
