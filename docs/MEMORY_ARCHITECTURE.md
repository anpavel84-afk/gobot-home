# Архив, темы и семейная память

SQLite WAL остаётся единственным хранилищем. Перед миграцией — online backup через
sqlite3.Connection.backup с integrity_check. Подтверждённый снимок перед изменениями:
data/backups/gobot-before-context-20261110T040121Z.sqlite. При первом создании archive
таблиц на непустой базе делается дополнительный before-archive-*.sqlite, включая WAL.
Резервные копии содержат частные данные, исключены из Git.

| Сущность | Назначение |
|---|---|
| messages / turns | Исходные тексты, провайдер, результат, completed/cancelled/error |
| archive_messages | owner, namespace production/diagnostic, статус, topic и episode |
| topics / episodes / turn_topics | Независимые темы, временные эпизоды, решение TopicRouter |
| topic_summaries | Версии атрибутированных выдержек, источники, boundary, generation |
| memory_facts | Явно разрешённые факты, owner/scope/provenance/confirmation, validity, supersedes |
| retrieval_chunks / archive_fts | FTS5 индекс исходных сообщений; только completed production |
| request_keys / utterance_drafts | Идемпотентность delivery IDs; интерфейс обновления черновика |
| provider_sessions / context_runs | Fresh execution, полученный thread, usage, состав пакета без приватного prompt |
| speech_segments | Реально переданный в TTS текст, segment ID, статус, клиентская playback-телеметрия |
| pending_actions | Конкретное ожидаемое действие с owner/conversation/expiry |
| memory_jobs / auxiliary_usage | Ограниченная локальная очередь, резервирование модельных затрат |
| timers | Дедлайны и состояние отдельно от сжатия истории |

conversation_id, topic_id, episode_id и provider thread ID различны. Старые
conversation помечены «тема не размечена», без заявления об автоматической семантической
сегментации старого архива. В полночь ничего не обнуляется. После 600 секунд паузы
открывается новый episode, исходная тема может продолжаться.

TopicRouter без LLM различает continue/new_topic/resume_topic/side_action/ambiguous.
Явная новая тема, изменение сущностей и последние реплики обоих участников влияют на выбор.
Неопределённая граница сохраняет диалог. До трёх ближайших обменов conversation/owner
дополняют контекст темы в общем token budget. Явный сброс задаёт границу этого окна.
Таймер сохраняет основную тему. Уточнение длительности привязано к pending_action
сроком 120 секунд. «Да» само по себе не авторизует файловые или домашние опасные действия.
Эвристика тем экспериментальная; название можно исправить в интерфейсе. Исправление
названия не является автоматическим переносом старых сообщений между темами.

Поиск — SQLite FTS5, Unicode, префиксы русских слов; scope ограничен в SQL до передачи
модели. Последние реплики берутся по теме и владельцу плюс окно текущей conversation,
без дублирования source ID и разрыва пары user/assistant. Запрос за
неделю покрывает темы/дневные интервалы. Оригиналы доступны через защищённый source
endpoint. Не найденный источник не заменяется выдуманной цитатой. Длинные исходные
сообщения могут не поместиться в retrieval budget и будут явно пропущены.

sqlite-vec / multilingual encoder пока не установлены и не заявлены работающими.
Проверка русского поиска показала отсутствие синонимического поиска. Это конкретное
ограничение текущей реализации, а не обещание семантической памяти.

Family: family:home, Personal: personal:<profile>, Guest: browser:<peer>/device,
Temporary: RAM-only. PIN-сессия и проверка owner выполняются gateway; voice similarity
не даёт доступ к частной истории. Unknown/ambiguous speaker использует гостевой контекст.
Голосовые ECAPA embeddings локальные, Windows DPAPI, raw enrollment не сохраняется.

Mock изолирован метаданными происхождения и исключён из production retrieval.
Одинаковый текст с новым request ID — новое намеренное обращение. Повтор request_id,
utterance_id или event_id не запускает новую модель; активный дубль возвращает конфликт,
завершённый — replay final, без повторного TTS. Browser partial STT — один редактируемый
черновик; только финальная/исправленная фраза уходит в chat с utterance_id. Черновики
браузерного STT не пишутся постоянно до отправки.

Прерванный сгенерированный текст сохраняется со статусом cancelled, ошибка — error;
эти сообщения не попадают в retrieval completed. Аудио generation и client playback
разделены. Web Audio onended — сообщение клиента, не доказательство, что человек услышал
звук. Отключение/потеря сети не означает успешное произнесение полного ответа.

Факты не добываются автоматически из вопросов или ответов модели. Добавление с consent,
исправление версией, удаление tombstone и очистка производных данных реализованы.
Удаление профиля очищает также его архив/факты/индексы. Рабочая SQLite не шифруется
целиком: используется доступ Windows-пользователя; биометрия и API-ключ защищены DPAPI.
Нужна отдельная политика удаления backup и провайдерского хранения.
