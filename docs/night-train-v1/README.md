Обычные инженерные решения в этом объёме принимаются без промежуточных согласований. Не останавливаться после плана, первых тестов или написания документации; пройти реализацию, интеграцию, бесплатную проверку, безопасную публикацию веб-кандидата и итоговый отчёт.

## Архитектурное решение

GoBot — единая личность и единый Brain, но не одна модель для любого вопроса:

`активация → активный STT → контекст/строгий разбор → проверка плана и прав → инструмент / рассказчик / B / C / эксперт → согласованные речь и экран`.

Для уже открытого B/C не добавлять вторую STT-цепочку. Сохранить существующие native-tool callbacks, включая проверенную обработку инструментов по стабильному транскрипту, под единым арбитром действий.

Погодный помощник — первая полноценная предметная реализация: данные → проверяемая интерпретация → отдельные speech/display представления. Таймеры — второй обязательный рабочий сценарий. Рассказчик — отдельный проигрыватель с позицией и ограниченной подготовкой аудио, не бесконечная Live-сессия.

## Что считается результатом

- Новый owner-only веб-режим на прежнем приватном HTTPS, предпочтительно `/device-next`, без изменения поведения `/device` и сравнительного `/demo2`.
- Реальные детерминированные команды, контекстные продолжения, отказ недоступным интеграциям и работающая политика действий; не декоративная mock-страница.
- Подключённые существующие STT/TTS/B/C-адаптеры для последующей **ручной** проверки в пределах действующих grants. При запрете — точная причина, а не скрытый mock или обход.
- Бесплатно проверенный браузерный проигрыватель рассказчика на явно помеченном тестовом материале; генерация и озвучивание нового текста работают через разрешённые адаптеры, но их платная приёмка не подделывается.
- Каталог голосовых фраз, manifest кеша, план и валидатор генерации; существующие 100 клипов сохранены. Отсутствующий клип не объявляется готовым.
- Прошивочный контракт/патч и, если окружение позволяет, воспроизводимый candidate build с SHA. **Установка на колонку запрещена этим поручением.**
- Отчёт: что реализовано, что проверено автоматически, что ожидает человека, какие ограничения остались, как откатить веб-режим.

## Как запускается работа

Публикация этого пакета сама по себе не запускает Codex, Gemini, GitHub Runner или новый scheduler. Owner передаёт `CODEX_OWNER_DIRECT.md` существующему локальному исполнителю. Ночной прогон идёт в его реальной рабочей сессии. Не создавать новый автономный supervisor и не обещать продолжение после прекращения работы исполнителя.

Один исполнитель владеет интеграционной веткой и deployment. Gemini — независимый review/QA либо альтернативный единственный ведущий, но не второй конкурентный писатель в тот же checkout.
