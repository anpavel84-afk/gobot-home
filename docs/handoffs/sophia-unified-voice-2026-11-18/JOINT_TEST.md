# Совместная проверка Софии после первого живого разговора

## Факты и цель

Владелец подтвердил настоящее пробуждение и голосовые ответы на физической
колонке. Вместе с этим он обнаружил ответы не на тот вопрос, прерывания речи,
зависание на «Слушаю» и сообщение о недоступной связи. После собственной
перезагрузки он увидел сообщение об исчерпанном лимите разговоров.

Первый пакет использовал три разрешённых запуска и девять ответов. Четыре
ответа достигли ограничения 512 выходных токенов. Журнал содержит девять
подтверждений физического завершения проигрывания; это не доказательство
плавности речи или правильности содержания. Текущие повторные отказы имеют
код `board_estimated_budget_exhausted`. Свежая отдельная проверка до перезагрузки
показала Wi-Fi/enrollment/протокол ready, работающий захват, пустые очереди и
отсутствие наблюдённых аварий. Она не исключает прошлый сетевой обрыв.

Оценка девяти ответов по сообщённому usage — $0.05887532; ранее созданная одна
служебная фраза — $0.0010728. Резерв B $1 не является фактической ценой ответов.
Отдельная стоимость входной транскрипции окончательно не подтверждена.
Экспертные задания, прямой экспертный STT и диктор эксперта ещё не запускались.

Цель следующей проверки — сопоставить одну известную реплику с событиями
распознавания границы, ответа, пакетов и реального проигрывания, затем проверить
Gemini, тот же marin и продолжение разговора. Детектор V4, его модель,
DET_MODE95, усиление и частоты не меняются.

## Подготовленный отдельный пакет

Новый вариант `joint_review` требует отдельного одобрения точного предложения.
Подготовка оставляет его отключённым, со сроком 0 и без записи активации.
Старые записи, потраченные попытки и неизвестные резервы сохраняются.

| Часть | Точный предел |
| --- | --- |
| Быстрые разговоры | 3 запуска по 180 секунд, до 12 ответов на запуск |
| Выход ответа | До 1024 токенов |
| Учтённые токены одного запуска | До 100 000, включая входной контекст |
| Оценка быстрых разговоров | $2, резерв $2/3 на запуск |
| Эксперт | 2 задания ARGON_DEEP по 90 секунд, контекст до 3000 токенов, результат до 6000 символов |
| Прямой экспертный STT | 2 попытки по 180 секунд |
| Диктор marin | До 12 ответов, 6000 символов суммарно, 3000 на задание |
| Оценка STT и диктора | $1 |
| Служебная фраза | Только существующий проверенный кеш; 0 новых генераций |
| Общая оценка API | $3, не гарантированный предел счёта провайдера |
| Срок | Одно окно 2 часа от однократной активации |
| Повторы | Автоматические платные повторы и продление отсутствуют |

CLI остаётся проектным Antigravity с точной моделью `gemini-4-argon-medium`.
Недоступный прямой Gemini CLI и исчерпанный Codex не используются. Google API
billing fallback не включается. Готовность каталога не доказывает остаток квоты.

## Как проводить проверку

Оператор сначала проверяет установленный commit, собственника процессов,
счётчики, срок, отсутствие активного ввода/эксперта, подключение платы и
соответствие исходников диагностике. После активации согласованного пакета
владелец произносит только следующую согласованную реплику, затем сообщает,
что увидел и услышал. В случае сбоя не повторять ту же попытку до сохранения
событий и проверки расхода. Не перезагружать плату до чтения её состояния,
если она не потеряла управляемость.

1. **Имя и вопрос без паузы.** «София, сколько будет два плюс три?» Проверить
   пять, целое начало вопроса, одну содержательную реплику и возврат к слушанию.
2. **Продолжение.** «А если прибавить семь?» Проверить двенадцать и сохранение
   услышанного контекста. Не считать только наличие звука успешным ответом.
3. **Имя отдельно.** «София», короткая естественная пауза, затем «Сколько будет
   четыре плюс шесть?» Проверить, что имя не расходует отдельный ответ и начало
   вопроса не теряется. Эта проверка относится к первой короткой реплике после
   локального wake; ручное касание и браузер не подменяют её.
4. **Целостная речь и Stop/Mute.** Короткое объяснение на 2–3 предложения,
   наблюдение до фактического конца, затем отдельная проверка остановки и нового
   вопроса. При обрыве отличать `max_output_tokens`, отмену, потерю кадра и
   сетевой разрыв; не менять одновременно пороги wake и кодек.
5. **Быстрый режим → Gemini → marin → продолжение.** Одна явная публичная задача
   сравнения двух простых вариантов, затем уточнение к услышанному результату.
   Проверить фактическое принятие задания, отсутствие дубля запуска, единственный
   владелец аудио и открытие микрофона только после физического конца речи.
6. **Прямой эксперт.** После выбора режима — одна длинная публичная задача
   длительностью более минуты с естественными паузами и явной поправкой.
   Проверить фактическую длительность STT, учёт поправки, единый голос и
   продолжение. Синтетическая 92-секундная запись сама по себе не заменяет эту
   проверку человека.

Шаги распределяются внутри трёх запусков, с проверкой оставшегося времени и
счётчиков перед следующим действием. При исчерпании или истечении окна работа
останавливается с конкретной причиной; счётчики не восстанавливаются.

## Диагностика и критерии

Сохраняются ограниченные события и числа: wake, ранняя граница реплики,
пропуск отдельного имени, причина окончания модели, начало/конец физического
проигрывания, закрытие ввода, очередь и фиксированный код разрыва транспорта.
Звук микрофона, личные тексты и ключи в эти отчёты не записываются. Если
понадобится отдельная запись голоса, она не подразумевается этим пакетом.

Успех — правильный ответ на заданный вопрос, непрерывная речь без обрыва,
корректное продолжение и наблюдаемый возврат к готовности после отказа или Stop.
Окончание генерации и отправка последнего пакета не заменяют подтверждение
физического проигрывания; даже такое подтверждение не заменяет слух человека.

Для вопроса о последнем фильме или другом меняющемся факте нужен проверенный
актуальный источник. Сейчас общего источника фактов в Brain нет. Исправленный
Google-маршрут даёт экспертный разбор, но не подтверждённый веб-поиск. Изоляция
CLI не ослабляется, а отсутствие источника должно объясняться конкретно,
без ложного утверждения, что вся София отключена от сервисов.
