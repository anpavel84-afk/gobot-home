# GoBot: запуск HOST-INTEGRATOR

Дата пакета: 18 ноября 2026 года, America/Sao_Paulo.

Это пакет передачи задачи новому исполнителю в чате Pro. Владелец поручил довести объединённую схему «София → быстрый Realtime / эксперт Codex → общий голос marin» до работающего backend, frontend и физической колонки. Данный пакет публикует аудит и задание; сама новая интеграция этим коммитом не устанавливается.

## Что читать

1. [EXECUTOR_PROMPT.md](EXECUTOR_PROMPT.md) — полное задание, актуальная область разрешённой работы, порядок интеграции и развёртывания, проверки и критерии завершения.
2. [AUDIT.md](AUDIT.md) — проверенные исходники, протоколы, ограничения, целевая архитектура и первичные источники.
3. Корневой `AGENTS.md`, актуальные сообщения владельца и `docs/CURRENT_STATUS.md` в фактической интеграционной базе. Исторические запреты следует сопоставить с последующим поручением владельца; действующие ACL и финансовые ограничения сохраняются.

Я поручаю реализовать и развернуть описанную систему на существующем PLAN и физической колонке Spotpear: backend, frontend и необходимую прошивку, с сохранением рабочей Софии и проверенным откатом. ## Важное для выбора базы

Ветка этого пакета создана от `master` только для публикации документации. Она не является готовой интеграционной базой прошивки или backend. Использовать нужно проверенную установленную Sophia V3, необходимые изменения PR #8 / PR #12 и актуальную рабочую копию PLAN, включая ещё не опубликованные изменения HOST-A. Полные SHA и ссылки приведены в аудите.

`docs/CURRENT_STATUS.md` остаётся единственным фактическим паспортом проекта. Этот каталог — датированный аудит и задание, а не второй текущий статус.

Репозиторий публичный. В пакет входят только документация, ссылки на исходники и несекретные контрольные суммы. Прошивки, полные резервные копии Flash, ключи, пользовательские записи и журналы остаются в существующем приватном хранении проекта.
