# GoBot Home boundaries
Work only in this repository. No paid/model calls by default. No firmware flash/OTA/NVS.
Never read, copy or mount CLI credentials. No shell from voice, no global installs, no firewall changes.
Brain, Bridge, voice and image services use 127.0.0.1. The owner's iPhone testing request permits a separate temporary mock-only phone gateway on the specific Wi-Fi IPv4, restricted to that subnet. No firewall/router changes, no credentials, history access, arbitrary proxy, CLI or shell through this gateway. Real agents remain blocked until OS containment and tool deny policy are verified.
Tests use mocks; preserve upstream SHAs and regression-test every patch. Do not claim mock audio is speech.
