GoBot · Browser Voice Lab

HOST-A · отдельная лаборатория

Говорите «Моника» в микрофон устройства, с которого открыта страница — телефона или ПК. Распознавание работает на PLAN; OpenAI пока заменён бесплатным тестовым протоколом.

MOCK — бесплатно. Настоящий Vosk распознаёт микрофон; OpenAI имитируется. В режиме REAL после локальной «Моники» звук поступает в OpenAI, затем вопрос — в существующий Brain GoBot, ответ — голосом marin. Сохраняются полные текстовые стенограммы, промежуточные результаты, ответы Brain, времена и ошибки локально на PLAN. Сырое аудио и ключи API не записываются. Spotpear/COM3 не используются.

Полная запись текстов включена по разрешению владельца. В каждой новой сессии текст Vosk, расшифровки OpenAI, вопросы и ответы Brain будут сохранены на компьютере PLAN. Аудио и ключи API не записываются.

Диалоговый режим. После ответа можно говорить без повторного имени в течение 16 секунд. Тишина возвращает в режим ожидания «Моника»; микрофон при этом остаётся включённым.
