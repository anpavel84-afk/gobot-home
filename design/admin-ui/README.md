# София — прототип центра настроек

**[Открыть закрытый интерактивный прототип](https://gobot-sophia-settings.proud-mouse-8733.chatgpt.site/)**

Доступ через ChatGPT владельца. Это отдельный дизайн-прототип: он не подключается
к PLAN, не включает микрофон и не применяет изменения к физической колонке.
В нём используется датированный, сокращённый снимок технического состояния.

## Что можно попробовать

1. Найти «погода» в таблице из 24 семейств умений; проверить фильтры категории
   и состояния; открыть боковую панель «Об умении / Настройки / Проверка».
2. В «Дом и погода» выбрать другой **пример** города из демонстрационного
   справочника, подтвердить место, поменять единицы температуры или ветра.
3. Нажать «Проверить изменения», сравнить старые и новые значения, сохранить
   макет. Перезагрузка страницы сохраняет эти значения в этом браузере.
4. В разделе «Изменения» вернуть предыдущие значения через ту же проверку.
5. Посмотреть отдельно сервер PLAN, его службы и внешние сервисы; изучить
   причины доступности и ограничений в разделах «Разговор», «Расходы»,
   «Диагностика» и «Люди и память».

Навигация содержит десять разделов. Таблица на узком экране превращается
в карточки. Вкладки, модальные панели и мобильное меню доступны с клавиатуры.
Скрытая мобильная навигация исключается из фокуса; Escape закрывает панель.

## Факты и демонстрационные значения

Снимок PLAN 20 ноября 2026, 13:44 BRT: runtime `66fcae0`, app `0.4.18`,
ready/fast, marin, Antigravity ARGON_DEEP. Погода включена, домашнее место
сохранено, координаты корректны. Срок окончания и общий денежный лимит
постоянного терминала отсутствуют; учёт продолжается: 4 разговорные операции,
14 ответов, экспертных задач в этом снимке 0.

В 13:45:42 BRT отдельный существующий `WeatherClient.current()` на PLAN
успешно получил проверенный ответ Open-Meteo за **887 мс**, возраст данных
при проверке **42 с**. Это проверка погодного источника, не задержка
от wake до звука и не приёмка голосового запроса.

Домашний город, координаты, реплики, ключи и приватные журналы в прототип
не перенесены. Выбираемые города — примеры. После смены примера явно
указывается, что успешная проверка относится к сохранённому месту на PLAN.

Постоянные единицы измерения, ручной пояс часов, яркость, громкость и часть
предпочтений обозначены «Проект настройки». Их значения — предложение UI,
не выгруженная конфигурация устройства. Weather.com/OpenWeather пока имеют
неработающие варианты с объяснением отсутствия адаптера. Переключатель
на экране не выдаёт право на новый сервис, память или расходы.

## Файлы и архитектура

- `index.html`, `admin.css`, `admin.js` — автономный frontend без библиотек
  и сетевых запросов к продуктовым API.
- `catalog.js` — 24 семейства, схема полей и сокращённый снимок; **не runtime
  allowlist** и не новый источник разрешений.
- `weather-command-reproduction.json` — бесплатное воспроизведение ошибки
  обработки обращения «София» в прежнем нормализаторе.
- `qa.json` — объём и ограничения выполненной проверки.
- `previews/` — изображения проверенного браузерного макета.
- [Дизайн-контракт](../../docs/design/sophia-admin-ui-20261120.md) — навигация,
  поля, состояние, конфликты, доступ, предлагаемые API и порядок интеграции.
- [CURRENT_STATUS](../../docs/CURRENT_STATUS.md) — единственный паспорт проекта.

Для просмотра из репозитория достаточно статически обслужить эту папку:
`python -m http.server --directory design/admin-ui 8080`.
Проверка синтаксиса: `node --check design/admin-ui/admin.js` и аналогично
для `catalog.js`. Никакой backend или API-ключ не нужен.

## Следующий этап подключения

В существующем приватном frontend требуется owner-bound API выбранной колонки,
чтение версий/давности/причин, проверка изменения, сохранение и отдельное
подтверждение применения. Старый `/api/device/profile` относится к другому
приложению и браузерному профилю: его нельзя прямо использовать для Spotpear.
Погода должна переиспользовать существующий find → confirm → source-check → save.
Голосовой дефект с префиксом «София» и отсутствие безопасной записи результата
погодного инструмента зафиксированы для следующей реализации. В этом UI-этапе
исполняемый backend и прошивка не менялись.
