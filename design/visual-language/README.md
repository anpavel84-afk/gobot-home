# GoBot Home — Visual Language v1.0

Откройте **GoBot_Visual_Atlas.html** в браузере: все 192 экрана, 72 лица, пиктограммы, стайлгайд и 12 интерактивных сценариев находятся в одном автономном файле.

**Важно:** Figma-коннектор вернул `Invalid planKey`, файл непосредственно в Figma не создан. Комплект содержит SVG и подготовленный нативный импортёр. Инструкции запуска — раздел 14 `STYLEGUIDE.md`. Настоящий импорт ещё требует проверки.

## Для просмотра

- `GoBot_Visual_Atlas.html` — интерактивный атлас без интернета.
- `previews/00-cover.png` — обложка.
- `boards/` — 25 редактируемых обзорных SVG-досок.
- `screens/` — 192 отдельных круглых SVG 240×240.
- `faces/` — 72 лица; `icons/` — 109 семантических пиктограмм.

## Для разработки и Figma

- `STYLEGUIDE.md` — основной документ: язык, состояния, правила, источники, полный реестр.
- `tokens.json` — цвета, размеры и motion.
- `design-data.json` — исходный список редактируемой геометрии/текста.
- `scenario-manifest.json` — сценарии и жизненный цикл.
- `figma-plugin/code.js`, `ui.html`, `manifest.json` — нативный импортёр.
- `docs/*qa.json` — границы выполненных проверок.

Все показатели погоды и состояния инструментов демонстрационные. Это дизайн-предложение, не утверждение о готовности функций GoBot или физической платы.

Шрифты не вложены. Макеты: Noto Sans Regular/SemiBold. Пиктограммы Font Awesome Free: атрибуция и CC BY 4.0 в `docs/FONT_AWESOME_LICENSE.txt`. Несколько семантических пиктограмм используют один исходный глиф.

Скрипты воспроизведения зависят от Python Pillow/CairoSVG и локального установленного Font Awesome; готовые SVG, HTML и импортёр этих зависимостей не требуют. Нативный импортёр работает без сетевых запросов. При создании локального плагина используйте ID, назначенный Figma, не придуманный ID.
