## Source and reproducibility

The OLD GoBot microWakeWord public code/CPU toolchain were inspected READ
ONLY (preserved main/H0 remains intact). Its pretrained weights were NOT
used to initialize any Monika network. Old GoBot TFLite 20,888 B actually
executed on ESP32-S3 historically, but lacked successful human acoustic
acceptance. Later old reference model: 60,912 B, test 13/15 positive,
7 false events over 198 synthetic negatives (616.89s), REJECTED.
These results are NOT a matched-sample model comparison.

New B-only training files:
- synthesize.py, synthesize_v2.py: locally create disjoint Russian synthetic
  speech with 5 training voice profiles, 1 validation, 1 test; include
  immediate spoken questions, tempo/pitch change and hard confusables.
- train_monika.py, train_monika_v2.py: original MixedNet streaming CPU
  training 204x40 native MicroFrontend, inference 3x40 INT8 per 30ms,
  output quantized uint8 probabilities, fully INT8 TensorFlow Lite export.
- evaluate_heldout.py: selected cutoff on Aleksandr validation then
  replayed model on excluded Elena independent synthetic speaker.
- synthesize_v3_holdout.py: 185 new samples on RHVoice Aleksandr-hq,
  separate new test voice profile; verified installed CC-BY-SA voice terms.
- merge_v3.py: V1/V2 TRAIN-only files, validation-only Aleksandr,
  Elena existing test plus new Aleksandr-hq; SHA256 verifies sources,
  excludes initially spoken standalone Monika from ambiguous negatives.
- train_monika_v3.py: 16,384 augmented windows from merged sources,
  2,500 CPU steps, boosted confusable negatives, spectral mic drift,
  label smoothing, and fresh trained-from-scratch INT8 export.
- evaluate_v3.py: fixes a threshold using ONLY validation speaker,
  then evaluates Elena and the fresh HQ test with any verbatim text
  duplicates between train/validation and test excluded.
- esp32_standalone: actual ESP-IDF 6.0.1 and TFLite Micro independent
  one-app proof; no firmware flash, no device audio or service changes.

All training used zero GPU, zero paid calls, zero personal audio. Each
source corpus is newly generated from PREINSTALLED, read-only CPU
Piper/RHVoice/espeak toolchains. TTS source texts and augmentations are
not the same as physical human/TV/room audio. All model files remain
private; none were committed into GitHub or passed to HOST-A.
